# 鸿蒙多端宠物养成小游戏 V1.0
## 项目简介
基于HarmonyOS ArkTS开发，实现**一次开发、多端部署**，适配手机/平板/智能手表；内置分布式数据流转（隔空投送宠物存档），包含完整氪金内购体系。

## 核心功能
1. 开局剧情：神秘包裹+三选一宠物蛋（章鱼/巨蛇/知更鸟），孵化器倒计时孵化动画
2. 宠物互动：点击触发多套反馈、闲置自动循环动作；饥饿值/开心值双养成数值
3. 养成系统：喂食、洗澡、装扮商城；部分装扮等级免费、稀有装扮氪金购买
4. 收益系统：开心值满额自动产出金币，充值氪金快速获取金币
5. 多端适配：一套代码自适应手机竖屏、平板横屏、手表极简UI
6. 分布式流转：支持跨设备隔空投送宠物存档、装扮数据

## 开发环境
- IDE：DevEco Studio
- 技术栈：ArkTS + ArkUI
- 部署：统一HAP包，多终端兼容
